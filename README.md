# CHIP-8 Emulator

Повнофункціональний емулятор інтерпретатора CHIP-8, написаний на C з використанням бібліотеки **SDL2**. Емулятор підтримує повний набір із 35+ інструкцій (опкодів) та забезпечує точне відтворення класичних ігор.

## Можливості
- Повна підтримка набору інструкцій CHIP-8.
- Графічний вивід через **SDL2**.
- Обробка введення з клавіатури.
- Вбудовані ROM-файли для тестування:
    - **Pong** (класична гра)
    - **Snake** (змійка)
    - **Space Invaders** (космічні загарбники)

## Як скомпілювати та запустити
Переконайтеся, що у вас встановлено `SDL2` та `clang` (або `gcc`).

1. Клонуйте репозиторій та перейди в папку:
   ```bash
   make
2. Для запуску використовуйте наступне 
    ./chip8 name_rom наприклад ./chip8 Pong.ch8
